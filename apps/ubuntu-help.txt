XUBUNTU, GIT CREDENTIALS MANAGER (GCM):
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
https://github.com/git-ecosystem/git-credential-manager
https://github.com/git-ecosystem/git-credential-manager/releases
https://github.com/git-ecosystem/git-credential-manager/blob/release/docs/install.md
https://medium.com/@techworldthink/setting-up-github-credential-manager-on-ubuntu-013210e02652
(1) download tarball
(2) generate soft-link to git-credential-manager in /usr/local/bin
(3) run `git-credential-manager config`
(4) verify git configuration, prefer on --global (user) file.
(4.1) check each next by by running `git fetch` from a existing remote repo, resulting message may be helpful.
(4.2) run `git config set --global credential.credentialStore secretservice`.
(4.3) on ~/.gitconfig, complete where needed this section:
"""
[credential]
	helper = /usr/local/bin/git-credential-manager
	credentialStore = secretservice
"""

XUBUNTU, git-bash-aliases, notes:
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
- windows, strategy to make file executable: use of PATH environment variable
- linux, strategy to make file executable: use of soft-links in /usr/local/bin and 'x' file permission.
- linux script files require 'x' (execution) permission; in windows thay are executable by default
- substitute `javaw` by `java`; for legacy purposes, it has been leaved as `javaw` in java-help text.
- substitute `git config --system` by `git config --global`
- change repository filenames, remove txt extension, leave as sh
- function taskkill (alias tk), adjust to manage linux's `kill`
- SpringToolSuite, lombok jar as javaagent in .ini file, and placed in STS root folder; in order to get lombok taken into java's classpath, STS must be launched from that same folder
